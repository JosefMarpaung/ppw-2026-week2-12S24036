## 📖 Narasi & Latar Belakang Pengembangan

> *"Sebuah aplikasi web yang hebat tidak hanya dinilai dari seberapa memikat tampilannya saat pertama kali dilihat, melainkan dari seberapa kokoh fondasi semantiknya, seberapa inklusif aksesibilitasnya bagi semua kalangan, dan seberapa akurat ia mencerminkan logika proses bisnis di baliknya."*

Sebagai mahasiswa tingkat sarjana Sistem Informasi di **Institut Teknologi Del**, Sitoluama, perjalanan akademik saya dibangun di atas persimpangan antara **rekayasa perangkat lunak antarmuka** dan **analisis proses bisnis**. Ketertarikan mendalam saya pada mata kuliah *UI/UX Design* serta *Analisis Perancangan Sistem Informasi (ANAPRANCIS)* mendorong saya untuk selalu memikirkan pengalaman pengguna (*User Experience*) sejak baris kode pertama ditulis. Di saat yang sama, pemahaman terhadap *Manajemen Proses Bisnis (MANPROBIS)* dan *Manajemen Proyek Sistem Informasi (MPSI)* menanamkan disiplin bahwa setiap tombol, formulir, dan tabel data harus bermakna dan mempermudah alur operasional.

Website portofolio tunggal (*Single Page Showcase Webpage*) ini dihadirkan bukan sekadar untuk memenuhi kriteria formal praktikum laboratorium, melainkan sebagai **artefak digital profesional** yang merangkum kompetensi akademik nyata. Dibangun tanpa ketergantungan pada pustaka pihak ketiga (*vanilla HTML5 & modern CSS*), proyek ini mengadopsi standar industri terkini: penulisan struktur semantik murni, kontras visual berstandar **WCAG 2.2 Level AA**, serta penataan tata letak responsif menggunakan **CSS Grid** dan **Flexbox**.

## 🎨 Filosofi Desain & Arsitektur Visual

Antarmuka ini dirancang dengan prinsip keterbacaan tinggi, hierarki visual yang jelas, dan sentuhan estetika modern yang profesional:

1. **Penerapan Aturan Pewarnaan 60-30-10:**
   * **60% Ruang Netral (*Dominant Background*):** Kanvas gradasi lembut (`#f0f4f8` ke `#d9e2ec`) dipadukan dengan permukaan kartu putih bersih (`#ffffff`) untuk memberikan ruang bernapas (*whitespace*) yang lapang dan elegan.
   * **30% Struktur & Tipografi (*Secondary Structure*):** Teks utama menggunakan *Slate 900* (`#0f172a`) untuk judul kontras tinggi, *Slate 700* (`#334e68`) untuk keterbacaan narasi yang ramah di mata, dan garis pembatas lembut (*border* `#e2e8f0`).
   * **10% Aksen Visual (*Contrast Accent*):** Sentuhan *Sky Blue* dinamis (`#0284c7` & `#38bdf8`) untuk tombol aksi primer, indikator tautan fokus, dan status capaian akademik.
2. **Harmonisasi Komponen Hands-on Lab:**
   * Mengintegrasikan komponen *Developer Profile Card* dengan spanduk atas bergradasi, foto profil asli mengambang dengan lencana status aktif, ringkasan biografi, kumpulan tag kompetensi, indikator statistik akademik, hingga tombol pintasan aksi langsung.
3. **Inklusivitas Aksesibilitas Digital (WCAG 2.2 Level AA):**
   * Menyediakan tautan *Skip-to-Content* bagi pengguna pembaca layar (*screen reader*) dan navigasi papan ketik (*keyboard*).
   * Indikator fokus `:focus-visible` berkontras tinggi pada setiap elemen interaktif (tombol, input formulir, dan hyperlink).

## 📋 Matriks Pemenuhan Spesifikasi Teknis Praktikum

Dokumen ini disusun untuk mempermudah evaluasi dan penilaian oleh Dosen Pengampu serta Asisten Laboratorium:

### 1. Struktur Semantik HTML5 (Bobot: 20%)
- [x] `<header>`: Memuat monogram logo identitas `JM`, nama lengkap pengembang, dan navigasi utama.
- [x] `<nav>`: Dilengkapi atribut aksesibilitas `aria-label="Navigasi Utama Portofolio"`.
- [x] `<main>`: Kontainer utama halaman dengan ID unik `id="main-content"`.
- [x] Minimal 3 `<section>` tematik independen:
  1. `<section id="tentang">`: Kartu profil pengembang dan galeri keahlian 3 kategori terstruktur.
  2. `<section id="portofolio">`: Galeri 4 proyek terpilih dan tabel rekapitulasi 10 proyek.
  3. `<section id="layanan">`: Diagram alur konsultasi 4 langkah dan formulir interaktif.
- [x] `<aside>`: Bilah samping semantik memuat identitas akademik IT Del, ketersediaan jadwal, tautan unduhan resume PDF, dan status akreditasi kepatuhan laboratorium.
- [x] `<footer>`: Memuat hak cipta resmi, ringkasan standar WCAG, navigasi cepat, kontak alamat `<address>`, dan tombol kembali ke atas (*back-to-top*).
- [x] Menghindari *div-soup* dan memaksimalkan elemen semantik (`<article>`, `<dl>`, `<dt>`, `<dd>`, `<time>`, `<figure>`).

### 2. Penyajian Data Tabular & Lists (Bobot: 15%)
- [x] Tabel Semantik Penuh: Memuat `<table>`, `<caption>` (aksesibel pembaca layar), `<thead>`, `<tbody>`, `<tfoot>`, serta atribut `scope="col"` pada header kolom dan `scope="row"` pada baris kode mata kuliah.
- [x] Wadah Responsif: Pembungkus tabel dengan `overflow-x: auto` dan *tabindex="0"* agar nyaman digulir pada layar perangkat bergerak.
- [x] Dua Jenis HTML Lists:
  - `<ul>` (Unordered List): Daftar menu navigasi, tag keahlian utama, galeri kompetensi, badge teknologi, dan jadwal konsultasi.
  - `<ol>` (Ordered List): Alur standar 4 tahapan layanan konsultasi proyek digital.

### 3. Komponen Formulir Interaktif & Accessible (Bobot: 20%)
- [x] Pengelompokan fieldset: Menggunakan minimal 2 blok `<fieldset>` dan `<legend>` bermakna:
  1. *Identitas & Kontak Pemesan Layanan*
  2. *Spesifikasi Teknis & Rincian Proyek*
- [x] Lengkap 8 Tipe Kontrol Input:
  1. `text`: Nama Lengkap Pemesan (`minlength="3"`, `maxlength="60"`, `autocomplete="name"`)
  2. `email`: Alamat Email Resmi (`autocomplete="email"`)
  3. `tel`: Nomor Telepon/WhatsApp aktif (`pattern="[0-9]{10,14}"`, `autocomplete="tel"`)
  4. `radio`: Kategori Klien (Mahasiswa, Dosen/Akademisi, Institusi/Industri)
  5. `select`: Pilihan Paket Layanan (UI/UX, ANAPRANCIS, MANPROBIS, MPSI, Web Semantik)
  6. `number`: Estimasi Durasi Pengerjaan (`min="3"`, `max="90"`, default 14 hari)
  7. `checkbox`: Fitur Tambahan Kustom (Audit WCAG, Responsive Mobile, Dokumentasi Sistem, Diagram BPMN)
  8. `textarea`: Rincian Catatan/Deskripsi Proyek (`minlength="20"`, `maxlength="800"`)
- [x] Hubungan Eksplisit: Setiap input terhubung langsung dengan pasangannya melalui `<label for="...">` dan `id`.
- [x] Validasi Native HTML5: Menggunakan atribut `required`, `placeholder`, `pattern`, `title`, dan teks petunjuk (*field hint*).

### 4. Estetika & Tata Letak CSS Modern (Bobot: 25%)
- [x] Terhubung melalui berkas eksternal tunggal [style.css](style.css).
- [x] *Universal Box-Sizing Reset*: `*, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }`.
- [x] Arsitektur Layout CSS Grid & Flexbox terencana tanpa *framework* eksternal.
- [x] Media Queries Responsif: Penyesuaian tata letak otomatis untuk Tablet & Ponsel pintar (`@media (max-width: 992px)`, `@media (max-width: 768px)`, dan `@media (max-width: 480px)`).

## 🚀 Panduan Menjalankan & Deployment

### 1. Menjalankan di Server Lokal (Visual Studio Code Live Server)
1. Buka folder repositori ini di VS Code.
2. Buka berkas `index.html`.
3. Klik tombol **"Go Live"** pada pojok kanan bawah bilah status VS Code (atau klik kanan pada editor lalu pilih **"Open with Live Server"**).
4. Browser akan otomatis terbuka pada server lokal dengan nomor port:
   ```
   http://127.0.0.1:5500/index.html
   ```

### 2. Mengunggah ke GitHub
```powershell
git add .
git commit -m "feat: complete week 2 html5 and modern css assignment"
git remote add origin https://github.com/JosefMarpaung/ppw-2026-week2-12S24036.git
git branch -M main
git push -u origin main
```

### 3. Mengaktifkan GitHub Pages
1. Masuk ke repositori GitHub Anda di `https://github.com/JosefMarpaung/ppw-2026-week2-12S24036`.
2. Klik tab **Settings** &rarr; pilih menu **Pages** di bilah navigasi sebelah kiri.
3. Pada bagian *Build and deployment > Branch*, pilih branch **main** dan folder **/(root)**, lalu klik tombol **Save**.
4. Tunggu 1&ndash;2 menit hingga tautan publikasi aktif muncul (contoh: `https://josefmarpaung.github.io/ppw-2026-week2-12S24036/`).
